Questions that come up

How do I play with other people?

One person starts a game and gets a code — two short words, like cars feed. Everyone else joins with it from the home screen, and you all get the same board or the same word.

Why does Similar Vibe need four players?

It is two teams of two. One person describes a word to their team-mate while the other team watches for a giveaway, and there is no honest way to play it with fewer — which is why the lobby says so rather than letting a game start that nobody can finish.

Does it work without a connection?

The solo games do, and so does Vibe Five, which is one device passed round a table and needs the network for nothing. The games you play together need a connection while you play them.

How do I change my name?

Tap the name on the home screen. It is only a nickname, shown to the people in the game you are in — there is no account behind it.

What happens to what I send?

The privacy page says exactly what is collected, where it goes and how long it is kept — including that a note written here becomes a public issue.

It says it cannot reach the game service

That is the connection to the game rooms. Check the network and try again, and if it keeps happening, write above: the note arrives with the game you were in, which is usually the thing that explains it.
